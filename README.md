## 📖 درباره پروژه

**PerShiaA** یک پروژه محتوایی و پژوهشی برای گردآوری، تحلیل و تولید دانش درباره **تمدن نوین اسلامی** است. این اندیشکده با تمرکز بر تحلیل مسئله‌محور، پیوند میان حوزه‌های مختلف دانش و نگاه آینده‌نگر، به تدوین نقشه راه جامع تمدن از سطح بنیادهای فکری تا سطح راهبرد و عملیات می‌پردازد.

### 🎯 ماموریت ما
- **نگاشت** بنیادهای فکری و مفاهیم کلیدی تمدن اسلامی
- **تحلیل** مسائل کلان در حوزه‌های فرهنگ، علم، اقتصاد و حکمرانی
- **تولید** منابع علمی، کتاب‌های سفید و توصیه‌نامه‌های راهبردی
- **ارتباط** میان پژوهشگران، نهادها و فعالان عرصه اندیشه و فرهنگ
- **ارائه** راهکارهای عملیاتی برای حرکت به سوی تمدن نوین

### 🏛️ محورهای تخصصی

| شماره | محور | حوزه فعالیت |
|:---:|---|---|
| ۰۱ | **اندیشه و نظریه** | فلسفه، انسان‌شناسی، نظریه‌های تمدنی |
| ۰۲ | **فرهنگ و جامعه** | هویت، خانواده، آموزش، رسانه |
| ۰۳ | **علم و فناوری** | نوآوری، قدرت تمدنی، آینده‌پژوهی |
| ۰۴ | **اقتصاد و پیشرفت** | تولید، عدالت، الگوهای پیشرفت |
| ۰۵ | **حکمرانی و سیاست** | نهادها، سیاست‌گذاری، ظرفیت‌سازی |
| ۰۶ | **راهبرد و آینده** | سناریوها، روندها، طراحی مسیر |

## 🚀 نحوه اجرای محلی

برای اجرای پروژه روی سیستم خود، مراحل زیر را دنبال کنید:

### پیش‌نیازها
- یک مرورگر مدرن (Chrome, Firefox, Safari, Edge)
- یک سرور HTTP ساده (برای جلوگیری از مشکلات CORS)

### روش ۱: با Python
```bash
# کلون مخزن
git clone https://github.com/masoudshafizadeh028-dev/PerShiaA.git
cd PerShiaA

# اجرای سرور محلی
python3 -m http.server 8000
```
سپس در مرورگر به آدرس `http://localhost:8000` بروید.

### روش ۲: با Node.js
```bash
# استفاده از npx serve
npx serve

# یا با http-server
npx http-server -p 8000
```

### روش ۳: با VS Code
- افزونه **Live Server** را نصب کنید
- روی `index.html` کلیک راست کنید → **Open with Live Server**

## 🤝 مشارکت

مشارکت شما ارزشمند است! PerShiaA یک پروژه جامعه‌محور است و از هر نوع مشارکتی استقبال می‌کنیم:

### انواع مشارکت
- 🐛 **گزارش اشکال** — مشکلات را در Issues ثبت کنید
- 💡 **پیشنهاد ویژگی** — ایده‌های خود را به اشتراک بگذارید
- 📝 **تولید محتوا** — کمک به نوشتن مقالات و منابع پژوهشی
- 🎨 **بهبود طراحی** — پیشنهاداتی برای تجربه کاربری بهتر
- 🔧 **توسعه کد** — ارسال Pull Request برای رفع مشکلات یا افزودن ویژگی
- 📖 **بهبود مستندات** — کامل‌تر کردن README و راهنماها

### گام‌های مشارکت
1. 🔱 مخزن را **Fork** کنید
2. 🌿 یک شعبه برای ویژگی خود بسازید: `git checkout -b feature/نام-ویژگی`
3. 💾 تغییرات خود را Commit کنید: `git commit -m 'feat: افزودن قابلیت X'`
4. 📤 به شعبه خود Push کنید: `git push origin feature/نام-ویژگی`
5. 🔀 یک **Pull Request** جدید باز کنید

> برای راهنمای کامل، فایل [CONTRIBUTING.md](CONTRIBUTING.md) را بخوانید.
